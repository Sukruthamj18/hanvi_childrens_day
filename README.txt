HANVI — MAGICAL CHILDREN'S DAY (Masha & Bear)

OPEN IT
1. In this folder, run:  npm install
2. Then run:             npm run dev
3. Open the local URL Vite prints (usually http://localhost:5173)
4. Tap the glowing door to begin Hanvi's surprise.

STORY FLOW
1. Knock knock — Hanvi peek photo on the door
2. Hug — masha-full hugs Hanvi's photo
3. Flowers — masha-flowers.mp4 + gifts fly to Hanvi
4. Chocolates — masha-chocolates.mp4 (Gemini video, loops) + chocolates fly to Hanvi
5. Fight — snow fight sway + BAM/POW + Hanvi laughing
6. Ending collage of Hanvi photos

VIDEOS
- assets/masha-flowers.mp4 — flowers giving
- assets/masha-chocolates.mp4 — Gemini chocolate / hug clip (autoplay loop muted)
- assets/masha-fight-sway.mp4 — fight sway
- assets/hanvi/ — Hanvi photos

EDIT
- index.html  — story text & scene structure
- style.css   — fantasy look, colors, layout
- script.js   — GSAP motion, voice lines, showers
- assets/     — images & videos

VOICE
Browser speech (Web Speech API). Tap the door first (required for sound).

Keep the assets folder next to index.html.
Google Fonts need internet; the rest works offline after load.
